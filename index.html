0–100 per game → Mean across 15 games Scoring rules ⌄
Game result
Average the independent test scores for a frozen program. Earlier entries use their recorded result.
Scale each game
100 × (result − lowest) ÷ (highest − lowest). The range includes coding agents, GUI agents and the human reference.
Rank participants
Take the arithmetic mean of all 15 scaled scores, weighted equally. Incomplete coverage is unranked.

What we learned

× 13/15
× 10/15
  1. 01Astra’s scripts favor game state, while Sol’s favor timing.

    GPT-6 Astra most often used task-relevant state (60% G3). GPT-5.6-Sol relied mainly on timing (63.6% G1). For Claude Opus 5 and Qwen3.8-Flash, half of the scripts reached G4.

  2. 02In Forza Horizon 5, the simpler controller scored higher.

    Sonnet’s script steered toward the nearby route. Qwen used a feedback controller to correct its steering. Its log shows the car leaving the road and triggering recovery at the wrong time.

    Route-following scriptPID development log
  3. 03Agents tested their fixes, yet many problems persisted.

    The first bar counts revisions whose next self-test reached the targeted situation. The second scores the problems that could be tested, with one point for a full fix, half for a partial fix and zero if the problem remained.

  4. 04Script execution took most of the game time in 10 of 12 example runs.

    Sol ran its scripts for 98.5% of game steps. Only Gemini-3.8-Flash and Kimi-K3 spent more steps playing directly.

  5. 05Sol detected crashes in Riders Republic but kept tricks on a timer.

    The script watched for a red screen to trigger recovery. A separate counter chose when to perform each trick, so a crash could trigger a reset while the timing rule that preceded it stayed the same.

    Riders Republic scriptDevelopment log
  6. 06Frozen scripts sometimes beat the same model playing through the GUI.

    Each mark represents one game. We compared a frozen script running on its own with the same model choosing actions from the game screen. Both models’ scripts won on Balatro, Kingdom Rush 5 and The King of Fighters ’98.

  7. 07A larger development budget helped some games more than others.
