# Coding4Games

This repository contains the static Coding4Games project page for GitHub Pages. It includes the leaderboard, game and model results, and available archived experiment evidence.

To preview the site from the repository root, run `python -m http.server 8000` and open `http://localhost:8000`. Independent test recordings are hosted in this repository's [recordings release](https://github.com/Coding4Game/Coding4Game.github.io/releases/tag/benchmark-recordings-20261115).
