# Coding4Games project page

This repository contains the Coding4Games website and its GitHub Pages deployment workflow. The site displays the 15-game benchmark, model and game results, and the available experiment evidence.

The [benchmark asset release](https://github.com/Coding4Game/Coding4Game.github.io/releases/tag/benchmark-recordings-20261115) contains the full independent test recordings and the static asset packs required by the site. To preview locally, extract the `pages-assets-*.zip` files into the repository root, then run `python -m http.server 8000` there.
